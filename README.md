# DevSecOps Labs

Hands-on DevSecOps portfolio focused on CI/CD, automation, containerization, Infrastructure as Code, cloud infrastructure and security scanning.

## Labs Overview

| Lab | Topic | Main Tools | Outcome |
|---|---|---|---|
| [Lab 01](./lab01-cloud-secure-server/) | Secure Cloud Server | AWS, Linux, Firewall | Secure VM setup |
| [Lab 02](./lab02-python-automation/) | Python Automation | Python | Log analysis automation |
| [Lab 03](./lab03-ci-cd/) | CI/CD | GitHub Actions, Bandit | Automated CI pipeline with security scanning |
| [Lab 04](./lab04-docker-containerization/) | Docker | Docker | Containerized application |
| [Lab 05](./lab05-kubernetes-basics/) | Kubernetes | Kubernetes | Local app deployment |
| [Lab 06](./lab06-terraform-iac/) | Infrastructure as Code | Terraform, AWS EC2 | Infrastructure provisioning |
| [Lab 07](./lab07-devsecops-pipeline/) | DevSecOps Pipeline | GitHub Actions, Bandit, Docker | Integrated security pipeline |

## Key Skills Demonstrated

- CI/CD automation with GitHub Actions
- Static security scanning with Bandit
- Docker image build validation
- Infrastructure provisioning with Terraform
- AWS EC2 lifecycle management
- Artifact generation and pipeline evidence
